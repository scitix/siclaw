# 子任务完成验收与完整输出恢复验收

## 故障依据

测试会话 2970112a-4944-4d7d-8044-05826d5e1dda 的 nodepool-061 子任务在约 4.7 秒内仅返回执行意图，没有工具调用，模型响应以 stop/final_answer 结束，Runtime 因此错误标为完成。nodepool-062 实际执行并生成完整报告，但批处理汇总只拿到短摘要，丢失尾部证据。另有子任务工具历史 4,000 字符裁剪和共享临时输出文件问题。

## 实现

- 子任务执行后以同一上下文验收任务完成情况，允许零工具分析任务正常完成。未完成最多续跑两次；阻塞、取消、错误和总时限仍生效。验收 JSON 不进入用户执行记录。
- 模型长度终止保留已有片段并继续生成；报告保留所有章节。批处理把完整报告传给汇总，超出输入预算时提供汇总会话自身范围内的受控文件引用。
- 工具全文在原安全检查及脱敏后保存，取消共享 /tmp 输出路径。Agent 与 session 共同决定隔离目录，目录 0700、文件 0600，拒绝符号链接并校验文件摘要。引用读取不开放任意文件路径。
- 并发调用通过 AsyncLocalStorage 关联各自输出。原始文件工具限制继续生效；后台任务读取仍检查所属会话。后台报告保存到父会话的受控存储。
- 后台命令支持有界 UTF-8 分页，完整报告支持受控分页及搜索。大输出的实时事件保留短预览与引用，原有结构化信息继续用于子任务卡片。
- 保留期 24 小时，启动时和每 10 分钟清理，覆盖重启遗留文件；运行中的命令输出不会被清理。存储写入串行执行配额检查，不为新输出驱逐尚未过期的证据。
- handoff 从会话历史恢复计划和任务编号；缓存淘汰保留受控输出直到过期清理。

## 限制
